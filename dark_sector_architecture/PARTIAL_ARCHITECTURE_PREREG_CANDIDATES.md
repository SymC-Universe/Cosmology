# PREG-CONGLOMERATE-PA-1

## Candidate title
**Single-rule late-time dual-function architecture**

### MFR-01 - Candidate claim

A single frozen GR-native conglomerate state, built from admitted structure/geometry variables, contains reproducible information about both:

1. collapse/lensing enhancement in shear/overdensity-dominated domains; and
2. altered expansion or growth suppression in expansion-variance/curvature-dominated domains,

without changing the state definition or sign rules between the two regimes.

This is a partial-architecture claim only.

### MFR-02 - Provenance

- DOMAIN_THEORY;
- FRAMEWORK_DERIVED;
- DATA_DERIVED from the conglomerated literature.

### MFR-03 - Target native object

Candidate state variables:
- expansion variance;
- shear scalar;
- averaged intrinsic curvature;
- domain expansion;
- matter density/environment;
- boundary/edge descriptors only if independently qualified.

The initial minimal state is based on native variables, not a newly invented scalar index.

### MFR-04 - Representation and validity regime

Late-time, nonlinear structure regime in standard GR.

The state is conglomerate/system level and must preserve spatial/domain organization.

Refuse when:
- no physically defensible averaging/domain scale exists;
- quantities are gauge/slicing dominated;
- the same state definition cannot be used across both functional regimes;
- the output is only an effective-fluid rewrite with no independently testable structure;
- the architecture variables are algebraically redundant with the baseline.

### MFR-05 - Strongest comparator

Frozen comparison family should include:
- standard LambdaCDM background prediction;
- density/environment-only model;
- strongest standard large-scale-structure predictor available for the same output;
- Newtonian N-body baseline where applicable.

### MFR-06 - Null / competing explanation

- local matter density alone explains both outcomes;
- standard environment/tidal metrics explain the result without the proposed architecture;
- apparent acceleration is fitting/light-propagation bias;
- gauge/slicing choice generates the inferred system state;
- separate mechanisms are required for the collapse and expansion branches.

### MFR-07 - Expected response

Under one frozen mapping:
- shear-dominated states should associate with stronger collapse/lensing or reduced local expansion;
- expansion-variance/curvature-dominated states should associate with reduced deceleration, altered expansion, or suppressed growth relative to matched baselines.

The exact endpoint and threshold remain to be qualified before freeze.

### MFR-08 - Decision rule

The dual-function claim can receive `ADDS` only if:
- the same frozen state definition is used for both branches;
- both branch-specific gates survive on untouched evidence;
- at least one predeclared joint metric shows added information beyond the strongest comparator;
- neither branch requires post-outcome retuning.

If only one branch survives:
- `PARTIAL_ADMISSION`, not full dual-function support.

### MFR-09 - Uncertainty / indeterminate zone

INDETERMINATE when:
- domain choice materially changes branch classification;
- covariance among state variables prevents attribution;
- the sign of the relevant architecture contribution is uncertainty-dominated;
- the baseline-equivalence interval includes the observed added value.

### MFR-10 - Independence / leakage

Development domains/volumes may define the state extraction.

P1 uses:
- new simulation volumes/seeds or external simulations not used for extraction;
- later observational confirmation only under a new empirical freeze.

### MFR-11 - Multiplicity

Freeze:
- domain scales;
- state variables;
- branch endpoints;
- redshift intervals;
- observable families;
- environment strata.

### MFR-12 - Untouched decisive test

Preferred qualification path:
- relativistic simulation volumes with domain-averaged expansion/shear/curvature extraction;
- matched standard baselines;
- new held-out volumes after freeze.

Einstein Toolkit full-GR cosmology is the preferred robustness route where practical; gevolution is a practical weak-field relativistic route for development and independent volume generation.

### MFR-13 - Explicit falsifier

The dual-function claim fails if:
- the same frozen state cannot reproduce the expected branch distinction;
- only one branch survives;
- density/baseline variables explain the outcomes equally well or better;
- the inferred effect disappears under gauge/domain/resolution robustness.

### MFR-14 - Failure consequence

- if both branches fail: retire C1 in the tested regime;
- if one branch fails: narrow to the surviving branch only;
- if baseline is equivalent/better: record `NO_ADDED_SYMC_VALUE` for the conglomerate added-value claim;
- preserve descriptive native GR findings.
