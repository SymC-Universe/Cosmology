## Delta 01 - retire new-mechanism interpretation

**Original plan:** preserve a possible standalone S-class claim that a joint E-sigma relational state represents added modal physics.

**Objection/evidence:** standard covariant and Newtonian-limit literature already contains shear-tidal/Weyl coupling, nonlocal evolution, silent-model common-eigenframe constraints, and nonlinear T/V-web divergence. The isolated external novelty/domain APQ review classifies mechanism novelty as unsupported while identifying a narrower predictive estimand as potentially unresolved.

**Change:**
- prohibit interpreting E-sigma noncommutativity, eigenframe mismatch, or mixed invariants as a new degree of freedom, new force, dark-sector component, or uniquely relativistic mechanism;
- treat the relational state first as a candidate diagnostic/reduced-order coordinate;
- standalone S-class activation remains on HOLD.

**Consequence:**
Any surviving immediate claim is M-class TOOL_ONLY / method utility unless a later separately frozen physical claim survives standard-dynamics comparators.

## Delta 02 - insert a cheap relational-descriptor known-truth gate

**Original plan:** proceed from representation qualification toward late-time predictive P1 design.

**Objection/evidence:** algebraic redundancy and normalization behavior of the candidate relational feature family are not yet qualified. Spending new simulation evidence before checking this would reverse dependency order.

**Change:** add `RELATIONAL_MODAL_DESCRIPTOR_PREFLIGHT_v0.1` before any late-time simulation.

The preflight will use synthetic symmetric trace-free tensor pairs with prospectively controlled marginal spectra and relative rotations.

Primary diagnostic:

\[
\kappa_{E\sigma}
=
\frac{\|[E,\sigma]\|_F}
{\sqrt{2}\,\|E\|_F\,\|\sigma\|_F},
\]

with local refusal when either norm is zero or non-finite.

The sqrt(2) normalization follows the Böttcher-Wenzel commutator bound so the diagnostic is bounded by 1 for finite matrices.

Required known truths:
1. common eigenframe / commuting pair -> kappa = 0;
2. rotate one tensor while preserving both marginal eigenvalue spectra -> marginal invariants remain unchanged while kappa changes;
3. simultaneous coordinate rotation of both tensors -> kappa invariant;
4. tensor exchange E <-> sigma -> kappa invariant;
5. zero-norm input -> REFUSED, not zero;
6. near-degenerate spectra -> kappa remains computable but eigenframe-direction interpretation is flagged independently;
7. mixed-invariant/eigenframe diagnostics are checked for redundancy and cannot silently replace the primary statistic.

**Consequence:**
If these known truths fail, the relational descriptor is REFUSED before any simulation evidence is spent.

## Delta 03 - separate descriptor qualification from predictive novelty

**Original plan:** candidate predictive test and descriptor definition were in one route.

**Objection/evidence:** a mathematically valid relational descriptor can still be scientifically uninformative because standard dynamics already contain the same information.

**Change:** split the program into:
- M0: descriptor/estimator qualification on known truths;
- M1-D: development-only standard-dynamics predictive preflight on nonconfirmatory simulations if M0 passes;
- P1-M: untouched confirmatory prediction only after M1-D and a renewed APQ-3 freeze.

**Consequence:**
Passing M0 cannot be described as scientific modal novelty.

**Original plan:** untouched gevolution realizations were the next candidate evidence route.

**Objection/evidence:** the isolated novelty/domain reviewer recommends first testing whether conditional gain exists in standard Newtonian dynamics, because otherwise a gevolution result could be misread as relativistic/SymC-specific.

**Change:** if M0 passes, M1-D will first test conditional predictive utility in a standard-dynamics development setting, with:

- all resulting simulations classified development evidence and permanently excluded from later P1 confirmation.

Exact implementation, epochs, tracking, and sample design require their own APQ before M1-D execution.
