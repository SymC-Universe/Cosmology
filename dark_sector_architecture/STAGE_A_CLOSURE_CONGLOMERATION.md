# Stage A Closure Conglomeration

Status: P0-D foundation synthesis

The literature already contains several two-way small-scale/large-scale closure families, so the residual cosmology question is narrower than "can feedback closure exist?"

## Existing closure families

- **General-fluid Buchert averaging:** structure enters domain geometry through kinematical and dynamical backreaction and averaged curvature; the averaged system remains explicitly unclosed without additional constitutive relations.
- **Zalaletdinov macroscopic gravity:** covariant averaging with connection/metric correlation tensors; formal geometrical closure exists, but the physical correlation sector still requires additional hypotheses.
- **Covariant macroscopic-gravity perturbation iteration:** perturbations generate correlation scalars that correct the background, which then updates the perturbations. This is a genuine iterative two-way route, but tested backreaction is small in standard-CDM regimes and the practical construction uses a restricted gauge implementation.
- **Multiple-scales GR:** explicit fast-scale to slow-scale backreaction and slow-scale to fast-scale evolution; practical calculations remain gauge-dependent and require detailed small-scale modeling.
- **EFT/coarse graining:** systematic UV-to-IR effective stress plus IR-to-UV tidal response; coefficients require matching and standard implementations normally presuppose conventional dark matter.
- **Mori-Zwanzig GR:** exact formal history/memory closure after eliminating unresolved degrees of freedom; the physical kernel remains to be derived or constrained.
- **Gauge-invariant averaging:** solves the representation problem but not the closure problem.
- **Perturbations on an averaged background:** supplies background-to-perturbation coupling but not a fully self-consistent perturbation-to-background return path at the same order.

## Refined R1 residual

The literature already answers "can two-way multiscale closure exist?" with several qualified yeses.

The residual is:

> Does there exist, or can one derive from native GR, a covariant/gauge-robust two-way closure between resolved matter/radiation/metric structure and large-scale geometry that spans the radiation era through nonlinear structure formation, requires no dark-substance ontology, and has enough predictive closure to face early- and late-Universe observations without outcome-fitted retuning?

The required closure must satisfy all of the following together:

1. no new dark substance or hidden medium as ontology;
2. standard GR as the native gravitational theory;
3. gauge/covariant robustness;
4. explicit two-way resolved-structure <-> geometry coupling;
5. radiation/pressure coverage through recombination;
6. nonlinear structure coverage at late times;
7. history dependence only when derived;
8. closure coefficients/kernels independently derived or constrained rather than tuned to desired dark phenomenology;
9. one parameterization across epochs;
10. simultaneous confrontation with CMB/BBN/BAO, growth, lensing, distances, galaxies, and clusters.

No admitted framework has yet been shown to satisfy all ten conditions.

## Current architecture consequence

If a cosmological broader Chi representation is eventually supported, the admitted foundations currently require at least:

- resolved dynamical modes;
- coarse-grained geometrical/correlation organization;
- history or closure information when the reduction is non-Markovian.

This is an investigative scaffold, not a formula for Chi. Lowercase chi is not introduced at this stage.

The remaining Stage A task is to determine whether any existing closure family can be specialized to the no-dark-substance hypothesis without violating its own assumptions. Only the irreducible remainder after that comparison becomes Stage B.
